# AssetHive 2.3.0

- 新增 Blender、3DCoat 导出与连接设置，统一导出目标入口；Blender 支持按需减面。
- 优化共享资产库启动、缓存恢复和缩略图加载，扫描与清理本机缓存时保留资产列表。
- 改善搜索响应，支持中文拼音、英文整词和有限错拼匹配，修复扫描期间搜索结果延迟的问题。
- 完善 Unreal Engine 多材质按名称匹配与复用，优化导出进度和结果反馈。
- 减少浏览、扫描和导出时对共享资产文件的写入，移除导出次数统计。
- 完善 Fab 免费 Megascans 下载、去重、预览去背景及法线修复。
- 修复 Windows 自动更新混用 EXE、MSI 安装方式的问题，更新时保留原安装目录和安装范围。
