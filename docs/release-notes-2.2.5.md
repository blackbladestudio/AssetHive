# AssetHive 2.2.5

Windows x64。

## 本次更新

- 新增后台自动下载更新：启动及运行期间每 30 分钟检查新版本，自动下载并校验更新包，下载失败不弹窗打断工作。
- 更新包就绪后，等待入库导入队列、资产保存和 UE 导出任务全部结束，再弹窗提供“立即更新 / 稍后”；选择稍后，本次运行不再重复提示同一版本，也可从更新页手动安装。
- 点击立即更新后再次检查任务状态，阻止新导入和导出任务；等待程序退出，再静默覆盖安装到当前目录，完成后自动重新打开，无需重复操作安装向导。
- 更新下载支持完整缓存复用、并发请求合并及损坏检测；开发预览不自动下载或覆盖更新。
- 包含 2.2.4 之后的扫描、元数据保存、标准标签和 Surface 导出修复。

## 安装包

- `AssetHive-2.2.5-setup-win64.exe`：独立安装程序，推荐使用。
- `AssetHive-2.2.5-Windows.msi`：供 BlackBlade Hub / 静默部署使用。
- `AssetHive-2.2.5-Windows-setup.exe`：深色安装界面，内部安装同一份 MSI。
- 每个安装包均提供 `.sha256` 校验文件。

后台自动下载和空闲更新流程从 2.2.5 开始生效；旧版本用户需先安装本版本。

## 已知问题

本机 UE 插件源码与 AssetHive 的植被 OPAQUE 裁切预算仍不一致：AssetHive 的 Bush / Grass 预算为 30 万 / 15 万面，插件当前仍按 3.5 万 / 1 万面处理。跨仓库一致性回归测试尚未通过，实际影响取决于所使用的插件版本。本次仅发布桌面端更新，未变更 UE 插件。
