# AssetHive 2.2.9

## 本次更新

- 第三方 3D Plants 保留原始 LOD0 风层、分块、源指纹和实际低 LOD 记录；托管入库后仍可对应原始变体。
- 提供 Nanite Masked、LOD、Opaque 三种植被导出方式。只有 LOD 携带 Billboard；缺少裁切变体时，Opaque 对该变体回退为 Nanite Masked LOD0。
- Opaque 导出标识改为 `Op`：材质实例后缀为 `_Op`；第三方资产的裁切表示目录为 `Op`，其余资产目录使用 `_Op` 后缀。
- Billboard 使用独立材质实例、父实例变体和对应纹理。普通 Billboard 仅保留 Shared，关闭交互及其他枝层；Micro 全部关闭。
- 补查真实叶根、封口细茎、连续扫描接缝和重复花叶组织，保留根部衰减。证据不足的岛继续保持待确认。
- 非 Micro 水生、沉水和散落植被按有风植被处理；Auto 根据资产全部原始变体的实际尺寸选择 Micro，手选 Micro 继续保持无风。
- 包含远端已有的预览抠像孔洞清理与边缘柔化更新。
- 修复 Windows 安装包缺少原生批量导入依赖及入库工作进程目录无效的问题；构建时实际加载模块并启动隔离工作进程检查。
- 配套插件在 Opaque / 低 LOD 新生角点插值后继续约束已声明的根区，避免固定根区被远端角点的权重抬升；原始 LOD0 权重保持不变。

## 版本配套

配套 Unreal 插件版本为 1.1.9。项目侧需使用对应插件源码构建；正式资产入库、Opaque 批量剪切和风层对应检查的结果单独记录在本次运行验收报告中。

## 安装包

- `AssetHive-2.2.9-Windows.msi`：供 BlackBlade Hub / Windows x64 静默部署使用。
- `AssetHive-2.2.9-Windows.msi.sha256`：安装包 SHA256 校验文件。

## 验证范围

桌面端导入回归 334 项、真实 Electron 原生导入集成 2 项通过；类型检查、Lint 与构建通过。配套插件通过隔离 UE5.8 编译、SyntheticWind 回归与真实裁切模型根区测试，原始 LOD0 权重保持不变。主项目全量 PIE 视觉效果及跨版本覆盖安装尚未验证。
